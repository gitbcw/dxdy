## 4. 账号角色切换验证

登录页代码支持通过预置手机号切换角色：

- 普通客户：`13888002233`
- 未认证机构：`13822003456`
- 宠物医院：`13821003456`
- 个人客户：`13877005678`
- 业务员：`13811001234`
- 制单员：`13833007890`

当前验证结果：

- 宠物医院客户：实测 `pages/home/home` 展示 `广慈宠物医院 · 认证机构`，`pages/mine/mine` 展示 `广慈宠物医院 / 宠物医院客户 / 已认证`，我的页出现重复“医院认证”入口。
- 制单员：实测 `pages/home/home` 展示 `孙文静 · 制单员`，待办区出现 `undefined 等待发货`；`pages/mine/mine` 展示 `孙文静 / 制单员`，当前待处理卡片也出现 `最近订单：undefined · 广慈宠物医院`。
- 业务员/代理商：实测 `pages/mine/mine` 展示 `陈一舟 / 代理商 / 已认证`，财务数据为 `累计提成 ¥28,600.00`、`可提现 ¥15,200.00`、`待抵扣 ¥1,400.00`；`pages/home/home` 首屏切到代理商工作台，包含代理状态、客户管理、客户订单、提成中心、提现管理、推广工具等入口。
- 登录页预置账号点击可用：退出当前账号后点击预置账号，再勾选协议并登录，可以切换角色。

建议：

已落地登录页 query 切换入口：

- 只预填账号：`pages/login/login?demoPhone=13833007890`
- 自动登录并跳首页：`pages/login/login?demoPhone=13833007890&autoLogin=1`

可用于切换的账号仍为上方 6 个预置手机号。下一轮如果需要更快切换，也可优先用页面路径自动登录到指定角色；若要继续深层交互，建议先分离模拟器窗口后用 Computer Use/系统点击重试。
